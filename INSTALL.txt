CatchMICE 한국어 / ENG 설치

1. ZIP을 압축 해제합니다.
2. GitHub의 catchmice/catchmice.github.io 저장소에서 Add file → Upload files를 엽니다.
3. GitHub_upload 폴더 안의 파일 4개를 선택해서 저장소 최상위에 한 번에 올립니다.
   index.html과 sw.js는 기존 파일을 교체합니다. i18n.js와 i18n-data.js는 새 파일입니다.
4. Commit changes를 누릅니다. GitHub Pages 반영 후 아래 주소에서 확인합니다.
   https://catchmice.github.io/?lang=en#home

이 패키지는 2026-11-23에 확인한 저장소의 index.html과 sw.js에 맞췄습니다.
그 이후 두 파일을 별도로 수정했다면 최근 변경사항을 비교한 뒤 병합하세요.

PC 왼쪽 메뉴와 모바일 상단의 한국어 / ENG 버튼에서 전환합니다.
브라우저는 마지막 선택을 기억하고 링크의 lang=ko 또는 lang=en이 있으면 그 값을 우선합니다.
기존 한국어 데이터 파일과 저장·지원 내역의 키는 그대로 사용합니다.

영문 콘텐츠 관리
- 행사 14건, 뉴스 39건, 채용 100건, 논문 22건의 영문 제목이 포함됩니다.
- 행사 설명(desc)과 뉴스·논문 요약(sum)도 포함됩니다.
- 새 항목에는 title_en, desc_en, sum_en 등 필요한 영문 필드를 추가할 수 있습니다.
- 예: {"title":"서울 전시회","title_en":"Seoul Exhibition","desc":"행사 소개","desc_en":"Event description"}
- 영어 입력이 없는 신규 항목은 한국어로 표시됩니다. 기존 외부 원문도 해당 사이트의 언어로 열립니다.
- 일부 고유명사, 브리핑 문장, 상세 학습 자료는 한국어로 표시될 수 있습니다.
