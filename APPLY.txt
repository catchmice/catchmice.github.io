CatchMICE 입찰 레이더 및 행사 스태프·서포터즈

한 번만 반영
  ZIP에서 나온 index.html, scripts/, .github/의 내용을 GitHub 저장소 최상위에서
  기존 파일과 병합하세요. .github는 숨김 폴더로 보일 수 있습니다.
  최종 변경 경로는 아래 세 개입니다.

    index.html
    scripts/update-opportunities.py
    .github/workflows/daily-update.yml

  GitHub의 웹 업로드 화면이 워크플로 파일 교체를 막으면 저장소의
  .github/workflows/daily-update.yml을 열고 편집 버튼으로 전체 내용을 교체하세요.
  기존 bids.json, staff.json, 영문 전환 파일은 재업로드할 필요가 없습니다.

자동 갱신 켜기
  저장소 Settings > Secrets and variables > Actions > New repository secret에서
  이용 승인을 받은 API 키를 연결하세요. 사용하려는 출처만 추가하면 됩니다.

    G2B_SERVICE_KEY         나라장터 입찰공고정보서비스
      https://www.data.go.kr/data/15129394/openapi.do
    WORK24_AUTH_KEY         고용24 채용정보 Open API
      https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?fullApiSvcId=000000000000000000000000000000
    VOLUNTEER_SERVICE_KEY   1365 봉사참여정보서비스 GW
      https://www.data.go.kr/data/15157582/openapi.do

  키는 소스코드나 채팅에 적지 마세요.
  Actions > Daily data update > Run workflow로 테스트합니다.
  이후 기존 일정에 따라 매일 오전 7시(한국 시간)에 실행을 예약합니다.
  API 승인과 실제 첫 실행 결과는 설치 후 확인이 필요합니다.

운영 방식
  입찰 레이더는 나라장터의 행사 관련 용역 입찰을 수집합니다.
  모집 탭은 고용24의 행사 관련 스태프·운영 인력과 1365의 행사 관련 봉사를 수집합니다.
  두 출처에 올라오는 서포터즈 공고는 해당 분류에 들어갑니다.
  다른 모집 사이트의 기존 공고는 보존하며, 신규 공고는 해당 출처와 별도 연동이 필요합니다.
  마감일이 없는 공고는 별도 종료일이 없을 때 14일 동안 기본 목록에 노출합니다.
  API 오류가 나거나 키를 설정하지 않으면 해당 출처의 기존 공고를 유지합니다.
  공고 제목·기관명 등 원문 데이터는 등록된 언어로 표시될 수 있습니다.

검증
  기존 공고 데이터로 화면, 검색, 유형·지역 필터, 마감 포함, 공고번호 복사를 테스트했습니다.
  수집기의 중복·정정·취소 처리와 마감일 처리도 모의 응답으로 확인했습니다.
